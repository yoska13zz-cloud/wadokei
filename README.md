# 和時計 Wadokei

江戸時代の不定時法で「いま」を表示するWebアプリです。日の出前の「明け六つ」と日没後の「暮れ六つ」を境に、昼と夜をそれぞれ六等分します。季節や場所によって一刻の長さが伸び縮みする時刻を、その日の太陽の位置から計算します。

A web clock that shows the current time in Japan's Edo-period temporal hours. Day and night are each split into six equal hours between the bells of Ake-mutsu and Kure-mutsu, so the length of an hour changes with the season and the location.

**公開ページ:** https://yoska13zz-cloud.github.io/wadokei/

**Creator:** Yoska

## 機能

- **和時計の文字盤**:正午を上にした24時間盤です。昼と夜の刻、鐘の位置(割駒)、十二支、刻の内(一刻を四つに分けた目盛り)、現代の時刻(12時間表記)を表示します。
- **いまの刻**:鐘の名前(九つ半など)、刻の内、次の鐘までの時間、この一刻の長さを表示します。
- **一日の鐘の一覧**:12の鐘の現代時刻と、一刻の長さを表で表示します。
- **場所**:主要都市から選ぶか、現在地を使うか、緯度・経度を入力します。主要都市は東京、London、Paris、Utrecht、New York、Longyearbyen などです。
- **時差(GMT)**:次の3つから選べます。
  - 端末の時刻に合わせる
  - 場所の標準時(夏時間は自動で切り替わります)
  - 手動(30分きざみ。+5:45、+8:45、+12:45、+13:45 も選べます)
- **日付**:日付を変えると、その日の太陽で計算した鐘を表示します。
- **六つの決め方**:次の2つから選べます。
  - 寛政暦(太陽が地平線下 7°21′40″)
  - 日の出・日の入り
- **高緯度・白夜・極夜**:実際の太陽どおりに計算します。太陽が六つの高さを越えない日は、昼(または夜)が一日中続くものとして表示します。
- **アラーム(iPhone)**:ショートカット「和時計アラーム」を使い、次の明け六つ・暮れ六つのアラームを時計Appに作ります。
- **日本語 / English**:画面右上のボタンで切り替えます。
- **オフライン対応**:ホーム画面に追加すると、アプリのように使えます(PWA)。

## ファイル

| ファイル | 内容 |

## 公開・更新の手順

GitHub Pages で `main` ブランチのルートを公開しています。

1. ファイルを差し替えてコミットします。
2. `index.html` を変えたときは、`sw.js` の `VERSION`(例:`wadokei-v9`)の数字を一つ上げます。上げないと、ホーム画面のアプリに古い版が残ることがあります。

手元で動かすときは、フォルダでローカルサーバーを立てます。

```sh
python3 -m http.server 8000
# http://localhost:8000 を開く
```

## iPhoneのアラーム

1. アプリの「ショートカットを追加」から、ショートカット「和時計アラーム」を追加します。名前は変えないでください。
2. 「明け六つ・暮れ六つにアラームを設定」を押すと、ショートカットが開いて時計Appにアラームが作られます。
3. 六つの時刻は毎日少しずつずれます。アラームはそのつど設定し直してください。
   - 設定済みの鐘は「設定済み」と表示されます。
   - 消してしまったアラームも、チェックを入れればもう一度追加できます。

アプリは `shortcuts://run-shortcut?name=和時計アラーム&input=text&text=5:05,17:53` の形でショートカットを呼び出します。時刻は端末の時計に合わせた時刻を、カンマ区切りで渡します。

## 計算について

- **太陽の位置**:NOAA の簡易式で、太陽の赤緯と均時差を求めます。
  - その日の太陽が指定の高さを通る時刻を、明け六つ・暮れ六つとします。
  - 精度はおおむね1分程度です。
- **鐘の区切り**:各刻は鐘が鳴った時点から始まり、刻の中ほどを「半」とします。
  - 「刻の内」は一刻を四つに分けた位置です。丑の刻の三つめが丑三つ時です。
  - 刻の区切り方には、時代や地域によって諸説あります。
- **白夜・極夜**:太陽が一日中六つの高さより上にある日(白夜)は、夜の刻を長さ0とします。一日中下にある日(極夜)は、昼の刻を長さ0とします。
- **保存する設定**:場所・時差・言語などの設定は、ブラウザの localStorage に保存します。
